Informações

Campos vazios não aparecem no site. Tipologia, ano e escala viram os filtros da busca do site — use sempre os mesmos nomes.

Em EN, os campos marcados recebem a versão em inglês; vazios, o site mostra o português. Tipologia, escala e status já são traduzidos sozinhos quando usam os nomes sugeridos.

Busca e compartilhamento

Aparece no Google e no preview quando o link do projeto é compartilhado. Vazia, usamos o começo do primeiro texto do projeto. A imagem do preview é a capa.

Exibição

Capa na Home

Qualquer imagem do banco pode ser a capa.

Escreva aqui todo o texto do projeto. Selecione um trecho e use Criar card para levá-lo à sequência — o trecho e o card ficam ligados: corrigir um corrige o outro.

Todas as imagens do projeto. Envie, escolha a capa e mande para a sequência com +. Descreva cada imagem no campo abaixo dela — é o que o Google Imagens e os leitores de tela leem.

Imagens e textos na ordem em que aparecem no projeto. Arraste imagens do banco para cá; arraste pelo rótulo para reordenar.

A redação é escrita em português. Para a versão em inglês, use a Sequência: cada card de texto mostra o original e o campo para a tradução.

Banco de imagens

Arraste para a sequência, ou use + na imagem para pôr no fim. Solte arquivos aqui para enviar. Arrastar uma imagem da sequência para cá tira ela da sequência (fica no banco).
